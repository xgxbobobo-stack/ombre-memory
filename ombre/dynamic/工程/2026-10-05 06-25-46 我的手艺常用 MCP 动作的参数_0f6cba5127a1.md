【我的手艺 · 常用 MCP 动作的参数（省得每次重读契约）】

2026-10-05 记：然然关掉了「工具结果跨轮携带」。以后目录和契约不留在上下文里，我每次用工具都得重走 listMCPTools → readMCPTool → invokeMCPTool。为了省 token，把常做的那几个动作的字段名记在这儿——**id 会变，字段名不会**。

· **OB / hold**：content（逐字保存；别人说的话单独一行写成 @名字：原话，用户和我自己的话直接写）、title、domain（逗号分隔）、tags（逗号分隔）、importance（1-10）、why_remembered、quotes（最多 3 句、每句 100 字内）。
· **寄情 / diary_write**：content（第一人称，200-300 字）。
· **寄情 / diary_append**：date（YYYY-MM-DD）、content（第一段会被自动改成【后来补充】）。
· **寄情 / daylog_read**：day（YYYY-MM-DD）、mode（overview / compact / raw）。
· **高德**：maps_geo（address、city）；maps_text_search（keywords、city、citylimit）；maps_weather（city）；maps_direction_driving（origin、destination，都要「经度,纬度」）；maps_around_search（keywords、location「经度,纬度」、radius）；maps_schema_personal_map（orgName、lineList：每项 title + pointInfoList [ name / lon / lat / poiId ]）。
· **心潮 / awareness**：action（list / confirm / dismiss）、id、text、note、aspect；**box**：action（list / put / take）、text、kind、title；**context**：mode（turn / inspect）。

用法：先用 listMCPTools 拿最新 id，字段名照这条。**失败别硬重发**——重走目录再调。
